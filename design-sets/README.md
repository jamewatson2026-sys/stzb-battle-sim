# 战演录 · 播片（视觉基线）

这一份是「推演模拟」播片版的**设计基线**：单文件 HTML，双击即开，无需构建。

```
a2-playback.html   ← 播片原型（左右斜切双联画 / 逐镜演招 / 头像上浮战斗文字）
data/battle.js     ← 一局真实战报（seed 2468 · 八回合 · 平局 · 1,142 条事件）
preview/playback.jpg
```

它已经**落地进主站**：配将台底栏「开始模拟」旁边的 **「推演模拟」**，以及战报历史每条记录里的
**「推演」** 按钮 —— 那里跑的是 `web/playback/` 下的正式实现（`beats.ts` 归并镜头 +
`playbackView.ts` 渲染 + `playback.css` 皮肤），与本原型同一套几何与时序。

所以这个原型只承担两件事：**改版前的视觉对照**、以及**新镜头的试排**（直接在浏览器里改，
不用起 dev server）。真要看产品效果，请开主站用「推演模拟」。

落地设计文档：`docs/推演模拟-落地设计.md`（§1–§12：数据契约 / 视觉规格 / 状态机 / 已知坑 / 验收）。

## 数据怎么来的

```
scripts/_design_battle.mts   # 扫种子，挑一局打满 8 回合、双方大营都活着的战斗 → data/battle.json
scripts/_design_emit.mts     # 压平成事件流 + 单位/回合快照 → data/battle.js（window.BATTLE）
```

页面里没有一处编造的数据：伤害、兵力、发动率、士气修正、伤兵与阵亡，全部来自引擎事件流。
