# 战演重设计 · 四套引擎外观提案

同一份真实战报（seed 2468 · 八回合 · 平局 · 1,142 条事件），四种互斥的界面语言。
每套都是**单文件 HTML**，双击即开，无需构建、无需服务器。

| 文件 | 提案 | 定位 | 一句话 |
|------|------|------|--------|
| `index.html` | — | 总览 | 四版并置、设计说明与入口 |
| `a-wartable.html` | 01 战演录 | 观战 | 两军对垒、招式当面撞出、底部年代轴推进 |
| `b-chronicle.html` | 02 战报卷宗 | 存档 | 纸质双页纪要：左页交战记录、右页阵容战功 |
| `c-console.html` | 03 战演终端 | 分析 | 指标条 + 回合轨 + 事件流 + 构成环形的遥测台 |
| `a2-playback.html` | 04 战演录·播片 | 观战（重做） | 左右斜切双联画：施法者｜目标同框，逐镜播片，增减伤同比，浮动战斗文字 |

## 打开方式

直接双击 `design-sets/index.html`。四套页面引用同一份 `data/battle.js`（经典 script，非 ES module），
因此 `file://` 下也能跑；立绘与图标走相对路径 `../public/…`。

## 数据是怎么来的

```
scripts/_design_battle.mts   # 扫种子，挑一局 8 回合、双方大营存活的战斗 → data/battle.json
scripts/_design_emit.mts     # 压平成 1,142 条事件 + 单位/回合序列 → data/battle.js（window.BATTLE）
```

页面里没有一处编造的数据：伤害、兵力、发动率、士气修正、伤兵与阵亡，全部来自引擎事件流。

## 四套的设计取向

- **战演录** — 电影感。漆底暗金、朱砂与靛蓝只用来标记阵营；中央只放一件事（招式名 / 普攻 / 分兵），
  左右卡面同步掉血；下方年代曲线是全局态势，点击可跳回合。
- **战报卷宗** — 印刷感。纸纹、墨线、朱印；中缝书脊把页面分成纪要与阵容两页；
  战功榜与兵力走势压成底部横带，整页可打印。
- **战演终端** — 遥测感。等宽时间码、行内引导虚线、方框事件标签；KPI 条 + 回合轨 + 事件表 + 环形构成同屏，
  每一次判定都可下钻。
- **战演录·播片** — 胶片感（本轮重做）。中间不再是留白，而是一块双联画：左（或右）是施法者，另一侧是本镜
  的全部受击目标；每个目标脸上压着这一下的伤害、伤害类型与剩余兵力，底部条给出兵力/属性/主加成与
  逐条增减伤来源。恢复与增益不占中间，直接浮在左右头像上——`【战法】恢复 +412`、`规避 +1 层`——向上飘、变淡消失。
