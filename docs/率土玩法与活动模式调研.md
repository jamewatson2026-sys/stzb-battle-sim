## 一、结论摘要（先看这 8 条）

1. **「活动模式」在率土里不是一层，而是四层**：① **赛季剧本**（主容器：决定地图、机制、结算方式）② **赛季内常驻玩法**（演武 / 巡察 / 时代战场 / 世界首领…）③ **限时运营活动**（周年庆 / 赛季主题活动 / 联动）④ **服务器与赛季形态变体**（经典服 / 青春服 / 爽玩版 / 军争模式）。
2. **赛季剧本官方登记 24 个**：3 个主线赛季（`群雄讨董` / `群雄逐鹿` / `决胜中原`）+ 21 个「其它征服赛季」；2026 年另有 `烽火无疆` `龙兴之地` 等新剧本（见官方预告，尚未进历史赛季页），故**实际已知 ≥26 个**。
3. **赛季进程是一条固定流水线**：`S1 → S2 → S3 → 备战区 → 征服赛季（自选剧本报名）`。**备战区**是所有赛季的中转枢纽。
4. **备战区规则（勿记错；下列条款出自官方 2025-05-19 公告的**青春服备战区**条目 —— 经典服备战区另有一套公告，本文未逐条比对）**：赛季结算后 1~2 天自动转入；主城变 **1 格临时营地**、无赛季目标、部分功能受限；**赛季武将与赛季战法被清除**；可在备战区按开服计划**自选剧本 + 自选入场时间**报名（可单人可组队，同队必分同服）；**同一角色同时只能报名一个赛季**；上赛季结算奖励须在**建立势力后 14 天内**领取。**经典服与青春服的备战区互相独立**。
5. **两条独立服务器线**：**青春服**（"不花钱抽卡"，2025-03-27 正式开启，S1 为 `太师乱汉` 主题）与 **爽玩版主题赛季**（S1/S2/S3，**30 天**周期，福利翻倍 / 建造提速 50% / 降肝减负，S3 以 `金印紫绶` 为基础玩法）。
6. **军争模式**是征服赛季的一种**赛季模式变体**（不是新剧本）：赛季内**常规赛季的武将 / 战法 / 宝物全部不可用**，靠铜钱重建 —— 「军争名将」卡包**每次招募必出五星**且价格随次数递增、**战法研修**（5000 铜钱随机得某类别 B 级以上赛季战法、不重复）、**工匠献宝**（10 万铜钱买一把稀世宝物）；赛季结束随备战区清除，结算与同名征服赛季一致。首个军争赛季 = 2024-01-18 的 `群雄逐鹿` 小赛季。
7. **赛季之外还有一条跨服单局制玩法线**：**时代战场**（2023-10-22 上线，跨服活动）→ 迭代到 **时代战场·郿坞夺宝**（2026-08-12，**30 分钟单局**、宝库探索 / 征讨贼寇 / **鸣金撤离** / 收藏品带出局外 —— 即"搜打撤"形态）。
8. **限时活动的三种常见形态**：**周年庆典**（天降五星自选、献礼积分、洛阳泊泊、**率土杀**、威动凉州）、**赛季主题活动**（如 `龙兴之地` 的箪食壶浆 / 画像 / 赛季知识答题试炼）、**联动**（甘肃省博物馆、中国航母）。

## 二、四层结构总览

| 层 | 是什么 | 周期 | 代表 | 决定什么 |
|----|--------|------|------|----------|
| ① 赛季剧本 | 主玩法容器，玩家在备战区**自选** | 一赛季（约 1~3 个月） | 群雄逐鹿 / 金印紫绶 / 太师乱汉 / 八阵图 … | 地图、出生规则、势力/阵营、专属玩法、天下大势、**赛季结算奖励** |

## 三、赛季体系

### 3.1 赛季进程

```
S1（第一赛季，新手）
  └→ S2（第二赛季）
       └→ S3（第三赛季）
            └→ 备战区  ←── 每个赛季结算后都回到这里
                 └→ 征服赛季（自选剧本 + 自选开服时间报名）
                      └→ 赛季结算 → 备战区 → …
```

- **备战区**：`主城变 1 格临时营地`、无赛季目标；转入后**赛季武将 / 赛季战法被清除**；原赛季入口删除，统一从服务器列表「已有角色 → 备战区」登录。
- **报名**：按系统公布的开服计划选剧本；**一人同时只能报名一个赛季**；组队报名则**全队分到同一区服**。
- **结算奖励**：在备战区**建立势力后 14 天内**领取，逾期消失；赛季卡包在**进入下一个征服赛季时**自动激活。
- **提前转入**：2025-05 起新增「提前转入备战区」功能（官方 2025-05-13 公告）。
- **经典服 / 青春服的备战区是两个独立入口。**

### 3.4 赛季形态变体

| 变体 | 何时出现 | 关键规则 |
|------|----------|----------|
| **军争模式** | 2024-01-18（首个 = 群雄逐鹿小赛季） | 常规赛季**武将 / 战法 / 宝物全部不可用**；军争名将卡包（铜钱招募、**必出五星**、价格 0→16 万铜钱递增、首次招募继承常规赛季最高进阶 + 默认解锁觉醒/深造/兵种）；**战法研修**（选指挥/主动/被动/追击一类，5000 铜钱随机得该类 B 级以上赛季战法、不重复）；**工匠献宝**（10 万铜钱任选一把已锻造稀世宝物）；日常/陈情/首占奖励**铜钱增加**；赛季武将与赛季战法**转备战区时清除**；不可施政「进阶强化」、家族引援受限；结算与同名征服赛季一致 |
| **爽玩版主题赛季** | S1/S2（2025-11 起）、S3（2026 年） | **30 天**赛季；阵营名将卡包前 10 个五星**额外赠送同阵营五星**；日常巡察 / 日常演武奖励（**含虎符**）翻倍；土地产量、经验、税收、战法经验转化**翻倍**；城内 / 城外建造升级时间 **−50%**、征兵速度 **+25%**；S3 以 `金印紫绶` 为基础玩法、守军难度介于 S2 与征服赛季之间 |
| **青春服** | 2025-01-13 测试 → **2025-03-27 正式开启** | 定位「**不花钱抽卡**」；扩大主城间距保障出生安全距离、新增政策「百废待兴」（可直接开发 2/3/4 级土地）；开放**名胜登临**玩法、外观商店、**家族**功能；S1 为 `太师乱汉` 主题；赛季结算**移除 SP 卡包招募次数与拜将坛奖励**；有独立备战区，首个青春服征服赛季为 `群雄逐鹿` |

## 四、赛季内常驻玩法（PVE / 跨服 / 对抗）

| 玩法 | 形态 | 关键规则（官方） |
|------|------|------------------|
| **日常演武** | 赛季内 PVE 闯关（队伍强度自测） | 2026-04-29 维护后的新服与备战区启用；**每天解锁 15 关、共 100 关**，难度递增；进度**存整个赛季**、换赛季重置；**每关通关奖励次日 0 点重置**，支持「**扫荡奖励**」一键领取；挑战**不再消耗铜钱**；守军**由当赛季系统守军构成**（Lv.1 土地守军 → 洛阳城区守军），战斗规则与打土地一致（敌我士气、点将台、四大营加成）；10-5 关难度 ≈ Lv.4 城区守军 |
| **日常巡察** | 每日 PVE 事件 | 与日常演武并列的日常奖励来源（爽玩版下二者奖励含虎符均翻倍） |
| **三英战吕布** | **世界首领**玩法（2026-04-15 起，第一赛季 + 征服赛季） | 每日 **6-9 / 12-15 / 19-22** 点开放；用**活动专用部队**（满兵力、不耗资源、不消耗真实兵力）挑战吕布军团，逐级战胜守军直至挑战吕布本人；**每日 5 次**挑战机会；按当日总灭敌与战损排名，本服前 10 得限时称号「天下无双」 |
| **时代战场·郿坞夺宝** | **跨服单局制**（搜打撤） | 征服赛季与备战区、历史势力值 ≥5000 可参与；**每日 8:00-23:30 匹配**；局外用时代币整备武将 / 战法 / 宝物，局内 **30 分钟**探索宝库（储库 / 聚居地 → 高级：金虎台 / 铜雀三台 / 遣将台，部分需先击败镇守猛将）、征讨贼寇（含定时刷新的**吕布营地**）、与其他主公交锋；**鸣金撤离**（迁城至鸣金台倒计时）成功后结算为时代币，收藏品转局外行囊；**被沦陷或超时未撤离则大幅折损**（宝匣内收藏品例外）；局内战斗节奏特化：**不连地、不耗体力、行军加速、征兵不耗资源** |
| 大地图对抗 | 赛季主体 | 出征 / 扫荡 / 驻守 / 连地 / 攻城 / 掠夺；同盟为组织单位（成员间可相互连地出征）；攻城宣战等规则逐赛季调整（`烽火无疆` `龙兴之地` 均改动过宣战与行军） |
| 内政与赛季进度 | 经营层 | 设施建造、征兵、**文臣施政**（赛季政策）、**天下大势**（赛季进度闸门）、陈情（每日任务）、名胜登临（青春服） |

> ⚠️ **旧版时代战场**（2023-10-22 首发）与新版差异大：旧版是**限时跨服活动**（10/22-11/8），有**武将寿命**（每小时 −1，归零阵亡）、单格主城设施不可升级、城池**个人占领**、新增 1 级城「亭」/ 2 级城「乡」、**影响力**排行榜（征战时间 / 势力值 / 攻城 / 灭敌 / 武勋 / 抢地 / 拆耐久综合）。引用时要区分版本。
